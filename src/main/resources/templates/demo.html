ユーティリティ機能デモ

📅 #temporals - 日付フォーマット

説明 式 結果
デフォルト表示 ${now}
作成時刻 ${createAt}
相対時間表示 th:if 今日 昨日
日本語形式 #temporals.format(now, 'yyyy年MM月dd日 HH:mm')
日付のみ #temporals.format(birthday, 'yyyy/MM/dd')
曜日付き #temporals.format(now, 'M月d日(E)')
年を取得 #temporals.year(now)
月を取得 #temporals.month(now)
日を取得 #temporals.day(now)

📝 #strings - 文字列操作

説明 式 結果
元のテキスト ${longText} ...
切り詰め（20文字） #strings.abbreviate(longText, 20)
大文字変換 #strings.toUpperCase('hello')
小文字変換 #strings.toLowerCase('HELLO')
文字数 #strings.length(longText)
空チェック #strings.isEmpty('')
含むチェック #strings.contains(longText, 'Thymeleaf')

🔢 #numbers - 数値フォーマット

説明 式 結果
元の数値 ${price}
通貨表示 ${price}
カンマ区切り #numbers.formatInteger(price, 3, 'COMMA')
元のレート ${rate} 0.1234
パーセント表示 #numbers.formatDecimal(rate * 100, 1, 2) + '%'

📋 #lists - リスト操作

説明 式 結果
リストのサイズ #lists.size(items)
空チェック #lists.isEmpty(items)
含むチェック #lists.contains(items, 'りんご')

✨ インライン展開 [[${...}]]

現在の日時は [[${#temporals.format(now, 'yyyy年MM月dd日')}]] です。

登録されたアイテムは [[${#lists.size(items)}]] 件です。
